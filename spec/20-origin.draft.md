# 主人公の初期状態（Origin — 逆算）

> 憲法第3条 骨2。アンカーは変化の**終点**。その転換が最大限に効く出発点を**逆算**で置く。
> 主人公＝画家（ゲームのプレイヤーキャラクター）。ただし序盤は**名前のない操作キャラ**として提示される。

## 終点（アンカー Locked）からの逆算

| | 終点（アンカー） |
|---|---|
| 名乗り | **自らが画家であると告白する** |
| 筆 | **彼女の肖像に背景を描き加える** |
| 位置 | 彼女の前に立っている |
| 関係 | 親愛と後悔が**氷解する** |

したがって出発点は、この4点すべての**裏返し**でなければならない。

## 初期状態

- **名乗らない。** 名前のない男として塔に入る。
  彼は自分を「画家」と呼ぶ資格がないと思っている——彼女に外の世界を語った男であることが、
  そのまま罪だから（アンカー Locked：外の世界を教えた軽率さへの後悔）。
- **描かない。** 20年、各地で絵を描き続けてきた（Locked）にもかかわらず、
  **彼女のための一枚だけは、20年ぶんの下絵のまま止まっている。**
  肖像は塔にあり（Locked）、塔には入れなかった（相談中）。描けなかったのではなく、届かなかった。
- **位置が届かない。** 20年、塔は異形のはびこる異常空間で、中に入れなかった（相談中）。
  彼は戻らなかったのではない。**入れなかった。**
- **後悔を独りで抱えている。** 彼女がまだ在ることを知らない。悼む相手すらいない20年。

## 差分の核

**独りで抱え、名乗れず、届かなかった後悔**
　　　　↓
**二人の前で名乗り、筆を取り、氷解する後悔。**

「名乗ること」と「描くこと」が同じ一つの動作になる地点が終点である。

## この初期状態が語りの構造を成立させる

アンカー Locked の「名前のない操作キャラ → 終盤で告白」は、
**装置ではなく人物の状態として説明される**：彼は仕掛けとして黙っているのではなく、
**名乗る資格がないと思っているから黙っている。**
→ 沈黙そのものが後悔の表現になり、正アンカーの片翼を封じるという欠点が解消される。

## Locked / Open
- **Locked（アンカーから導出・ユーザー明示に基づく）**:
  - 20年後、画家は塔に戻ってくる
  - 序盤は名前のない操作キャラとして提示される
  - 20年経ってもシャーロットを忘れていない
  - シャーロットの肖像は塔にあり、彼はそこに背景を描き加えることになる
- **Open**:
  - 塔に入れるようになったことを、彼はどう知ったか（噂を聞いた／毎年通っていた／その他）
  - 20年間の生計・境遇（詳細は決めない方針。必要になったら引く）
  - 彼が「彼女はもう居ない」と思っているのか、何かを期待して来たのか
    （＝肖像が応えたときの反応の大きさが変わる。**骨3の冒頭に直結**）
  - 病・死期といった設定を採るか（Notion 参考。**未確認。現状は採らない**）
