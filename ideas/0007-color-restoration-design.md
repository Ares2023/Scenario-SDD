# 色の復元機構の設計 —— 問題A/B/C への提案

## 対象
`spec/00-anchor`（絵画の状態・具体面）／ `spec/10-opposition` ／ `spec/30-spine#beat-21b`〜`#beat-30`
／ `spec/40-cast/10-knight#arc`

## 前提（ユーザー明示・Locked）
- 魂を与えられた絵画は**一部の色を失っている**。肖像は**色とともに一部の記憶も失っている**。
- 主人公は**狂乱の絵画に色を加えて普通の絵画に戻せる**。**正しい色は事前に調べる必要がある。**
- 結末：肖像を復元 → 野原へ持ち出す → 背景を外の風景へ描き直す（騎士も描き加える）→
  彼女は画面外へ消え、**本当の別れ**を告げる。
- 騎士は**最後に話せたことで赦しを得る**。

**以下はすべて AI 提案（未承認）。**

# 問題A：告白と色の復元の順序

## 穴
色を戻せば記憶が戻る。ならば **「彼女が思い出す」が「彼が名乗る」より先に起きる。**
Locked「ラストシーンで自ら告白する」（どんでん返し）が、**機構に先回りされて無効化される。**

## 案1：復元 → 彼女が思い出す（告白は起きない）
Locked 違反。**却下。**

## 案2：告白 → 復元
彼が先に名乗る。**なぜ今なのかが説明できない。** 20年黙った男が、動機なく口を開くことになる。**弱い。**

## 案3（推奨）：**肖像の最後の一色は、画家本人しか知らない**

他の絵の色は調べられる（問題C）。**だが肖像は違う。**
20年前にその絵を描いたのは彼である。その一色は**調べても出てこない。** 世界に彼しか知らない。

したがって：
- 彼が**その色を出せること自体が、彼が画家であることの証明**になる。
- **告白は台詞ではなく、筆の動作になる。** 名乗ることと描くことが同一の行為になる
  （`spec/20-origin` の終点定義と一致）。
- **順序問題が消滅する。** 告白と復元が**同時**に起こるので、先後を決める必要がない。
- どんでん返しは守られる：彼女が思い出すのは**塗った後**。読者も同じ瞬間に知る。

> **さらに**：この案は「調べる」という機構に**最後だけ穴を開ける**。
> 全編を通じてプレイヤーは調べて塗ってきた。最後の一枚だけ、**調べる先が自分自身になる。**
> ゲーム機構がそのまま主題になる。

**推奨：案3。**

# 問題B：「狂乱」の実体は何か

## なぜ要るか
問題1〜3の回答により、**人物としての壁が全部消えた**（`spec/10-opposition` 訂正）。
残る唯一の外的抵抗が「色を失った絵」である。**ここが空だと捜索行はただの収集作業になる。**

## 案α：襲ってくる／暴れる
戦闘になる。**本作の温度に合わない。** 加害者のいない物語に敵を作ることになる。**推奨しない。**

## 案β（推奨）：**狂乱＝正しくない記憶の反復**

色を失った絵の中の人物は、**欠けた記憶のまま、同じ場面を繰り返している。**

- 騎士の絵は、**暴徒が来た夜を繰り返している。** 誰も来ない扉を、何度でも守り続けている。
- 訪問者を別人と取り違える。会話が噛み合わない。同じ台詞を返す。

**この案の強み：**
- 危害ではなく「**見ているのが辛い**」という種類の抵抗になる。主題と温度が一致する。
- **壁と解法が同じ場所にある。** ループを観察することが、欠けた色を推理する手がかりになる。
  「この場面には本来あるべきものが映っていない」という欠落として提示できる。
- 色を戻す＝**欠けた記憶を返す**＝ループを終わらせる。機構が一本になる。

## 統合提案：**シャーロットの「正気の周期」は、狂乱の周期そのものである**

Locked に「死の直後は我を失い、時間とともに周期的に正気を持てるようになった」がある。
これは**他の絵の狂乱と同じ現象**として統合できる。肖像も色を失っているのだから当然である。

→ そして **色を戻すほど、正気の時間が長くなる。** ゲームの進捗が、そのまま彼女の回復になる。
→ `spec/30-spine#beat-23`（正気の周期が長くなるにつれ近づいてくる）と完全に噛み合う。

**推奨：案β＋この統合。**

# 問題B'：最も苦い帰結（要承認・主題に直結）

上記を認めると、**「普通の絵画に戻す」とは何か**を決めねばならない。

**提案：普通の絵画に戻るとは、魂がその絵に縛られなくなることである。**

- だから騎士は赦しを得て**終われる**。
- だからシャーロットは最後に**消えられる**。
- ——**色を戻すことは、救うことであると同時に、送り出すことである。**

> **画家が最初から最後までやっていたのは、別れの準備だった。**
> 彼はそれを知らずに始める。途中で知る。**それでも続ける。**
> これが `spec/10-opposition` の中心的対立の実体になる。

**タイムリミット（Locked）との整合：**
放っておけば彼女は**狂乱のまま消える。** 何も残らず、別れも告げられない。
色を戻せば**正気で消える。** 別れを告げられる。
→ 制限時間は残り、**選択の意味も残る。** 彼が選んでいるのは「消えるか否か」ではなく、
　**「どう別れるか」**である。Locked の「**本当の**別れを告げる」がここで効く。

# 問題C：「正しい色」を調べる情報源

| 源 | 内容 | 評価 |
|---|---|---|
| 1. 塔の実物 | 色あせた布、調度、窓の外の景色。現物照合 | 基本レイヤー。序盤の教示に向く |
| 2. 他の絵・スケッチ | 無事な絵に同じ対象が描かれている | 相互参照。中盤の複雑化に使える |
| **3. 正気に戻った魂の証言** | **一枚直すと、次の一枚の色を教えてくれる** | **推奨・主軸** |
| 4. 画家自身の記憶 | 滞在中に彼が見たものだけ分かる | **見なかったものは分からない**＝20年の不在が欠落として効く |
| 5. シャーロット本人 | 記憶を失っているので**聞けない** | **聞けないこと自体が機構**。下記 |

## 推奨：3を主軸に、1/2/4を補助、5は「聞けない」形で機能させる

- **3 が連鎖を作る。** 直した順に次が開く。探索の順序が世界の側から与えられ、
  同時に「人を救うと、次の人が救える」という形になる。主題と一致する。
- **5 が構造を決める。** 一番聞きたい相手に聞けない。だから**彼女の肖像は最後に回る。**
  他を全部直してから戻ってくる——これが Locked の結末順序（騎士→肖像）を自然に生む。
- **4 の欠落が画家の罪を描写に変える。** 彼が知らない色は、彼がそこに居なかった時間である。

## 派生：騎士の絵の色は誰が知っているか

### ~~推奨：画家自身の記憶（源4）~~ —— **撤回**

~~画家は滞在中、同じ塔で騎士を見ている。生前の騎士を覚えているのは今や画家だけ。~~

**騎士の来歴の確定により成立しなくなった（`ideas/0008` 第2部）：**
騎士は**擬態を続けていた**。シャーロットが描いた絵は**立派な騎士**（ともに Locked）。
→ **画家が見たのは飲んだくれの男だけで、立派な騎士を一度も見ていない。**
→ 画家の記憶では正しい色に届かない。**源4 は騎士の絵には使えない。**

**差し替え先**：発現前の宮廷を知る人物（＝宮廷側の協力者）の記憶を、
別の絵の回想を通して取り出す。詳細と主題上の利得は `ideas/0008` 第2部。

（対案：肖像を部分的に先に直して彼女から聞く → 順序が入り組み、
　「肖像は最後」という構造が崩れる。**推奨しない。**）

## 残る穴（未解決のまま置く）

- **なぜ画家に色が戻せるのか。** 魂を込めたのはシャーロットの力である。
  なぜ第三者の筆がそれを解けるのか。**機構が未説明。**
  → 候補：彼女が魂を込めたのは「思いを注いだ絵」だけ（`ideas/0006`）であり、
  　その一枚には**彼女が見ていた色**が焼き付いている。復元は魔術ではなく**照合**である、とする。
  → **要検討。ここは審査 2-1（機構審査）を通っていない。**
- **失われた「一部の記憶」の範囲**。全部忘れたのでは Locked「待っていた」が崩れる。
  推奨：**待っていることは覚えている。相手の顔と名が像を結ばない。**
- **色を失う原因**。誰が奪ったのか、自然に褪せたのか、20年の異常空間の副作用か。
  → 「奪った者」を置くと加害者が生まれ、「加害者のいない物語」（Locked 群の帰結）が壊れる。
  　**推奨：自然な褪色。塔の力が弱まる進行と同じもの。**
