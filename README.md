# scenario-sdd

物語のシナリオを、**AIを用いた仕様駆動開発（SDD）**の手法で構築するためのプロジェクト。

## このプロジェクトの位置づけ

- ここで育てるのは **手法とシステム（テンプレート）** であって、具体的なシナリオそのものではない。
- 個別のシナリオは、この構造をテンプレートとして **別のブランチ／別の場所** で育てる。
- したがって本リポジトリの成果物は「ドキュメントの書き方・順序・拘束のかけ方のルール」である。

## 中核となる考え方

SDD の本質は、**AI と合意を重ねながら「背景（意図・制約）」と「生成物」を分けて管理し、AI に予期しない編集をさせずに大規模な文章を正確に生成させる**ことにある。

ただし物語シナリオは、ソフトウェアの SDD と決定的に違う点がある：

- ソフトは「仕様＝正解」を事前に定義できるが、創作は**評価基準そのものが曖昧で、生成してみないと良し悪しが判断できない**。
- よって確定順序を「抽象度」ではなく **物語的重要度（＝核かどうか）** で決める。

この手法の全原則は [`method/00-constitution.md`](method/00-constitution.md)（憲法）に定める。
